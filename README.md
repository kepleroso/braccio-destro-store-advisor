# Braccio Destro Store Advisor

Plugin WordPress/WooCommerce che collega il negozio a Braccio Destro (https://www.ceotrust.it) con una chiave in sola lettura.

Pubblicato su https://wordpress.org/plugins/braccio-destro-store-advisor

Ogni tag di versione (es. `1.0.1`) viene caricato in automatico su WordPress.org dal workflow in `.github/workflows/deploy.yml`.
